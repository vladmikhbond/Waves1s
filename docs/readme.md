# хвильове число

Середовище складається з гармонійних осциляторів (пружинка + грузик)
m - маса грузика, k - жорсткість пружинки
кругова частота осцилятора   ω = (k/m)**0.5

v = ω/К     К - хвильове число

K = ω/v = (k/m)**0.5 / v

k/m       v        K
0.01    0.099      0.1 / 0.099 = 1.010
0.04    0.200      0.2 / 0.200 = 1
0.16    0.397      0.4 / 0.397 = 1.007
